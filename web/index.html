O que significa necessidade de caixa?

max(0, −menor saldo diário): aporte disponível desde a data-base para manter os saldos não negativos. Não é perda esperada, VaR, custo de crédito nem recomendação de financiamento. O cenário-base desta carteira já tem déficit.

Sobre o estudo

Estudo editorial interativo do RiskLab Trade. Quatro atos, um gráfico protagonista e recursos operacionais recolhidos. Interface em HTML, CSS e JavaScript modular, com motor de caixa independente da apresentação. Animações usam requestAnimationFrame e Web Animations API. A preferência de movimento reduzido é respeitada.

O projeto também inclui uma API Java 17 para conferência de cálculos em BigDecimal, disponível no ambiente de operações, e uma trilha separada de pesquisa em Python e SQL. O gráfico desta página é calculado em JavaScript. Abrir pesquisa quantitativa ↗
