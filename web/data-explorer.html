PYTHON → SQLITE → SQL → ANÁLISE

Um caminho que pode ser reproduzido.

  1. Fonte: referências cambiais diárias BCB/SGS, consultadas pela API existente.
  2. Ingestão Python: valida datas e preços, identifica duplicações e registra o hash do payload.
  3. SQLite: carga incremental por moeda e data; execuções ficam registradas com contagens de qualidade.
  4. SQL: calcula retornos com LAG, sem preencher datas, e consulta o histórico das execuções.
  5. Navegador: explora os dados da API atual. O warehouse Python é reproduzível por CLI; não está sendo apresentado como serviço Python permanente.
python analysis/scripts/market_warehouse.py \
  --input web/market-snapshot.json \
  --database /tmp/risklab.sqlite

WITH returns AS (
  SELECT currency, date, price / LAG(price) OVER (
    PARTITION BY currency ORDER BY date
  ) - 1 AS return_rate FROM quotes
)
SELECT * FROM returns WHERE date >= '2026-01-01';
