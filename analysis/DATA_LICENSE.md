# Dados

Fonte: Banco Central do Brasil, Sistema Gerenciador de Séries Temporais (SGS).

- USD/BRL: série 1.
- EUR/BRL: série 21619.
- GBP/BRL: série 21623.

Dados de referência de venda, expressos em reais por unidade de moeda estrangeira. Recorte 2016–2025. Data de consulta e hashes dos arquivos constam em `reports/experiment.json`.

O portal de dados abertos do BCB identifica a base sob **Open Data Commons Open Database License (ODbL)**: https://opendatacommons.org/licenses/odbl/1-0/ .

As cópias dos dados e a base derivada mantêm essa licença e a atribuição ao Banco Central do Brasil. Alterações neste projeto: validação, seleção de datas comuns, cálculo de retornos e composição de exposição sintética. Não há endosso do BCB.

A licença MIT do código não relicencia os dados oficiais.
